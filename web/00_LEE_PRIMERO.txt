❓ FAQ
═══════════════════════════════════════════════════════════════════════════

Q: "Is my API key secure?"
A: In MVP: stored in browser localStorage (basic security)
   In Production: stored on server only (see DEPLOYMENT.md)

Q: "Can I use for free?"
A: Yes! Use LocalAI (completely free, runs locally)
   No internet required after model download

Q: "How much does it cost?"
A: Depends on provider:
   • LocalAI: $0 (free)
   • Mistral: ~$0.01 per project
   • OpenAI: ~$0.005 per project
   • See API_KEYS_GUIDE.md for all

Q: "Does it work offline?"
A: LocalAI/Ollama only (requires model download first)
   Cloud providers (Mistral, GPT, etc.) need internet

Q: "Can I customize the agents?"
A: Yes, edit src/subagents.ts
   Each agent has: id, name, layerId, description, systemPrompt

Q: "Will my projects be lost?"
A: Only if you clear browser cache/cookies
   For persistence: deploy backend with database
